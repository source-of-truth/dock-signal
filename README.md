# Dock Signal

Небольшое приложение для macOS, которое показывает занятый своп, нагрузку на память и загрузку CPU на первой странице иконки в Dock.

**SWAP** показывает объём занятого свопа в десятичных МБ или ГБ. **MEM** показывает текущий уровень memory pressure в macOS: один зелёный сегмент означает норму, два жёлтых — повышенную нагрузку, три красных — критическую. При отсутствии данных число отображается прочерком, а индикатор давления остаётся серым.

**CPU** показывает среднюю загрузку всех ядер. Длина полосы соответствует проценту загрузки, а цвет меняется от зелёного через жёлтый до красного. Процент виден по клику на иконку.

Прокрутите колесо над иконкой или проведите по трекпаду двумя пальцами вверх или вниз. Страницы движутся по кругу. На трекпаде страница следует за пальцами, короткий жест возвращает её назад, инерция не переключает следующую страницу. Разрешите Dock Signal в настройках macOS → Конфиденциальность и безопасность → Универсальный доступ. Повторно вызвать запрос можно через «Включить прокрутку…» в контекстном меню иконки. Через это же меню можно выбрать страницу вручную.

Вторая страница показывает свободное место на томе домашней папки в десятичных ГБ и IPv4 интерфейса Wi-Fi. Если адрес отсутствует, виден прочерк. Третья показывает текущую скорость приёма (↓) и передачи (↑) через физические интерфейсы Wi-Fi и Ethernet в байтах в секунду. Для первого измерения нужны два отсчёта. Виртуальные интерфейсы VPN и loopback исключены.

Показатели обновляются раз в три секунды. Нажмите на иконку для текстовой расшифровки. Окно можно закрыть, иконка продолжит обновляться.

## Сборка

Понадобятся macOS 14 или новее и инструменты разработчика Apple с компилятором Swift.

~~~sh
bash build.sh
~~~

Скрипт собирает приложение под архитектуру текущего Mac, подписывает его локально и печатает путь к готовому файлу Dock Signal.app. Перенесите его в папку приложений перед первым запуском. После замены локально подписанной сборки macOS может потребовать заново включить Dock Signal в настройках универсального доступа.
