# Dock Signal

Небольшое приложение для macOS, которое показывает занятый своп, нагрузку на память и загрузку CPU прямо на иконке в Dock.

**SWAP** показывает объём занятого свопа в десятичных МБ или ГБ. **MEM** показывает текущий уровень memory pressure в macOS: один зелёный сегмент означает норму, два жёлтых — повышенную нагрузку, три красных — критическую. При отсутствии данных число отображается прочерком, а индикатор давления остаётся серым.

**CPU** показывает среднюю загрузку всех ядер. Длина полосы соответствует проценту загрузки, а цвет меняется от зелёного через жёлтый до красного. Процент виден по клику на иконку.

Показатели обновляются раз в три секунды. Нажмите на иконку для текстовой расшифровки. Окно можно закрыть, иконка продолжит обновляться.

## Сборка

Понадобятся macOS 14 или новее и инструменты разработчика Apple с компилятором Swift.

~~~sh
bash build.sh
~~~

Скрипт собирает приложение под архитектуру текущего Mac, подписывает его локально и печатает путь к готовому файлу Dock Signal.app. Откройте его или перенесите в папку приложений.
